# JEPA Transformer Model

Public core-model repository for a financial time-series transformer using point-in-time market, macroeconomic, fundamental, event, and news-derived features. The model and core implementation are being developed for an open-source release.

The repository is reserved for:

- model architecture and training code;
- model and experiment configuration;
- evaluation code and meaningful tests;
- reproducibility and public technical documentation.

Raw data, credentials, provider-specific acquisition scripts, ad hoc helpers, private working notes, checkpoints, and generated outputs are kept outside this repository.

This is an early-stage project, so the repository is intentionally sparse while data availability and point-in-time constraints are validated before model implementation. Public model documentation and a specific open-source license will be added before the first code release.
